# 源码项目发布检查

当前定位：上游提供原生运行、移植和构建基础；本项目维护深度 Mod、地图源码、菜单/控制扩展及 AI/MCP 集成。当前只发布源码、脚本、Skill、补丁和说明，不发行原生游戏 App、地图 App 成品、预编译上游工具、游戏素材或 DataPacks。项目组成适用 MIT、GPL 和其他来源许可，不把整个装配运行时称为 MIT。

## 只读检查命令

```sh
# 检查当前工作区，包括 Git 忽略文件；排除 .git 元数据
python3 -B scripts/check_release.py

# 检查将要发布的实际源码目录
python3 -B scripts/check_release.py --root /absolute/candidate/source

# 检查实际 ZIP，不解压、不执行、不修改附件
python3 -B scripts/check_release.py --archive /absolute/candidate/source.zip

# 检查器的回归测试
python3 -B -m unittest discover -s tests -p test_check_release.py -v
```

无错误返回 0；任何已检测错误返回 1。结果为 JSON，不回显疑似凭据值。候选 ZIP 支持根目录文件或单一包裹目录，不支持加密/多层嵌套发布包；过大文件/包、符号链接及危险路径直接报错。运行输出在终端；若需保存，使用仓库外的任务报告目录，不输出到源码。

检查包括：必要许可/来源文档、原始许可摘要、补丁与版本锁摘要、补丁新增 SPDX 与逐文件台账一致性、已声明组件与文件锁一致性，以及已知游戏/密钥/存档/数据包后缀、App、意外二进制、少量高置信凭据模式。图像二进制也不属于当前源码发布范围；有许可的 Reicon SVG 仍随原通知保留。

[GPL 机器清单](gpl-components.json)与[人工来源记录](gpl-components.md)一起维护。修改 SPDX、补丁或通知后先审查实际变动与许可，再修改清单；不要为让检查通过直接更新哈希或把待核验改为已验证。当前检查通过仍显示权利审查待办。

装配脚本将 GPL 正文、来源文档及原始许可通知一并复制到外部工作区的 docs/、licenses/；不改变 `MacNativeGames/` 代码或锁定文件哈希，也不会把这些通知自动写入最终游戏 App。此行为不认证二进制分发条件。

## 发布前人工确认

- 核对实际发布目录/ZIP，而不仅是 Git 跟踪列表；Git 自动源码压缩包只包含提交内容，不会包含未提交的本地许可修复。
- 检查源清单和新增代码来源，核对原版权、许可、修改通知及生成源首选修改形式。
- [生成数据来源](generated-data-provenance.md)中的授权与输入缺口未关闭，不得改写为“已获授权”。
- 素材清单只用于定位；SVG、JSON 和文本也可能涉及权利，不能因通过 UTF-8 检查就认定原创或可分发。
- 秘密扫描仅覆盖部分模式，不识别所有 MCP token、隧道凭据、改名密钥或编码载荷，发布者仍需人工核查。
- 旧发行按[历史复核](historical-release-review.md)单独处理；当前检查不追溯认证历史。

检查不是法律合规、安全认证、完整 SBOM 或游戏功能验收。CI 只检查已提交代码；本地修改需提交推送后才能获得对应远端结果。对象码发行或发布范围改变时，重新评估，不直接扩白名单。
